# Kadro Site

Public landing page for Kadro, a practical business assistant/operator service for busy local businesses.

## Design read

Reading this as a practical B2B service landing page for busy local operators, with a precise, masculine, low-BS business-assistant language, leaning toward Linear/Vercel restraint with a warmer service-business edge.

## Commands

```bash
npm install
npm run dev
npm run verify
```
